BOS / CHoCH on the ATR×2 adaptive tier

The same four worked examples as market-structure-events-examples.html, but every panel now uses one volatility-scaled rule — threshold = 2 × median ATR14 — instead of a hand-picked fixed threshold. Purple = causal zigzag; dots = confirmed pivots labelled HH/HL/LH/LL; dashed verticals = break events (only CHoCH labelled, with forward-20-bar net); top strip = per-bar bias. Marquee events were re-picked at this scale and normalised by each day's ATR, so panels 3–4 are ordinary days, not tail-vol.
