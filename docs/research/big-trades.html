How this is put together
  • Data — the existing tick cache only (data/cache/ticks/*_day.parquet), RTH segment, 09:30-16:00 ET. Nothing is fetched, so re-running is free.
  • Aggressor side — checked against the cache, not assumed: B prints sit above the local 41-trade mid (lifting the offer, buy), A prints below it (hitting the bid, sell).
  • Sweeps — a resting-size order arrives as a burst of fills. Sweep mode glues consecutive same-side fills within 250 ms and 1.00 pt into one event, then applies the threshold, so a 300-lot order shows up as 300 rather than six prints of 50.
  • move +5m — trade price 5 minutes later minus the print price. It is a description of what happened next, not a backtest: no entry rule, no stop, no costs.
